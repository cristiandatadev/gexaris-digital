Archivos:
- index.html
- styles.css
- script.js

Publicación rápida en GitHub:
1. Abre el repositorio donde quieres publicar la invitación.
2. Sube estos tres archivos a la raíz del repositorio.
3. En Settings > Pages selecciona Deploy from a branch.
4. Branch: main / root.
5. Guarda y espera a que GitHub publique el enlace.

La música es "El Danubio Azul" de Johann Strauss II, cargada desde Wikimedia Commons.
La grabación usada está publicada como CC0 / dominio público.

IMPORTANTE SOBRE CONFIRMACIÓN:
La sección de RSVP funciona sin servidor: crea el mensaje de confirmación y abre el menú de compartir del celular para enviarlo por WhatsApp/Mensajes. Así no requiere una cuenta externa ni exponer un teléfono dentro del código.
