CÓMO VERLA EN VS CODE
1. Abre esta carpeta en VS Code.
2. Instala la extensión Live Server.
3. Clic derecho sobre index.html.
4. Elige "Open with Live Server".

CÓMO SUBIRLA A GITHUB
Sube TODO el contenido de esta carpeta dentro de:
  /almita/

La dirección quedará:
  https://gexarisdigital.com/almita/

IMPORTANTE
- El archivo principal se llama index.html (sin acento).
- Las rutas ya son relativas y funcionan con GitHub Pages.
- La música se carga desde Wikimedia Commons y es una grabación CC0 de El Danubio Azul.
- En script.js puedes agregar un número de WhatsApp en la variable whatsappNumber.
- Para poner fotos reales, reemplaza la sección de galería o agrega imágenes dentro de assets/.
